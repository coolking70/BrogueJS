# 历史开发与验收脚本

此目录原样归档未被当前 package.json、源码测试或当前门禁调用的旧脚本，不要求可运行。它们依赖已不存在的旧证据目录、旧项目布局、某些历史提交及本机工具；不要把它们作为当前门禁入口。

| 范围 | 说明 |
|---|---|
| `u*` / `ur*` | 状态、随机流、黄金样本捕获、反事实及分阶段验收。 |
| `w*` | 法杖、魔棒与其他物品效果的 CE oracle 和浏览器验证。 |
| `x*` | 勘察、路径审计、自然局观测与收尾验收。 |
| `extract*` / `merge*` 及其他脚本 | 历史数据抽取、转换和补丁工具。 |
| `root/` | 原子项目根目录散落的四份 CJS 数据转换脚本。 |

当前可运行入口在仓库根 `package.json`。测试仍消费的 `u03-state-contract.json` 保留在根 `scripts/`；CE 参照由根 `scripts/fetch-ce-reference.mjs` 拉取。
