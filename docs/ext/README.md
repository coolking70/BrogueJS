# 扩展模式（二次开发）路线

本目录记录 BrogueJS 在 CE 移植之上的 RPG 化二次开发。主线（经典 CE 模式）的约定见 `AGENTS.md` 与 `docs/`；本目录只约定扩展部分。

## 总原则

1. **扩展模块不需要对齐 CE。** 新系统的规则、数值、交互按本项目自己的设计来。阶段 0 当时不查 CE 源码；阶段 1 起若在 CE 对齐规则文件接钩子/策略端口，仍按维护者本轮要求尽量 `ce:fetch` 后 `test:full`，验证经典路径未受影响。
2. **经典 CE 模式保持不变。** 扩展全部挂在开局可选的"扩展模式"下；经典模式下扩展代码完全不执行，现有测试、黄金 trace、生成基线必须继续通过且不改断言。理由：扩展分支最终要合回 main（main 会部署到公开试玩页）；现有测试是防误伤的安全网；主线保持干净才能继续同步 CE 新版本。
3. **扩展模式内部也保持录像可重放。** 所有改状态的输入仍经 `game.executeCommand` / `executeItemCommand`，随机数走引擎随机流。这不是为了对齐 CE，而是为了让复杂系统的 bug 可复现、可调试。
4. **低耦合、模块化。** 每个模块是一个可独立启用的扩展，代码在 `src/ext/modules/<模块>/`，通过底座提供的钩子与数据定义接入，不直接改引擎规则代码。
5. **玩家与 NPC 共享规则。** 等级、属性、职业、种族、信仰、技能等设计成任何生物都能拥有的组件，而不是玩家专属字段（见 `references/totalwar-notes.md`）。

## 阶段

| 阶段 | 模块 | 内容 | 与主线耦合 |
|---|---|---|---|
| 0 | 扩展底座 | 注册表、引擎钩子、数据定义格式、扩展存档区块、录像头记录扩展、开局模式选择 | 唯一需要在引擎插入钩子点的阶段，不改规则 |
| 1 | RPG 成长 | 经验与等级、属性加点、技能树、职业/种族/信仰 | 低 |
| 2 | 叙事 | 可对话中立 NPC、对话树（条件/效果）、立绘展示、剧情事件 | 低，主要是界面 |
| 3 | 类魂战斗 | 敌人攻击预警格、多回合攻击、体力、闪避、韧性/硬直、弹反、篝火 | 中 |
| 4 | 大型敌人 | 单体占 2×2、3×3 格：占位、按体型寻路、视野与目标、渲染、Boss 场地生成 | 高 |
| 5 | 多层战场与世界地图 | 世界地图 → 区域 → 战场 → 个人遭遇；部队用多格单位表示 | 最高，先出设计与原型 |

每个阶段结束都停下来交给维护者审核，确认后再开始下一阶段。
