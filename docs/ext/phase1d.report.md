## 规则与提交

- learn-skill / equip-skills / use-skill 都走 executeCommand→扩展命令。revision、精确 payload、前置 AND、学习费用、全局/单项取较宽松的 none/soft/hard、已学/类别/重复/槽位均统一检查
- 装配提交完整 active/passive ID 数组并保留槽序，耗时/专注/CD保留策略读配置。未学习/未装配不能使用；取消、拒绝、过期目标不扣费、不推进、不取骰，合法 miss 正常支付
- attack/move/wait/search 复用原即时核心、原确认和原耗时。攻击保持快慢武器及速度符文免费动作语义；搜索只执行一次手动搜索，不额外连搜充能。普通移动拒绝占用格及会转换成楼梯/传送门/祭坛其它动作的碰撞，不变成攻击或嵌套命令
- 动作起点效果在即时核心前建立，逐 strike 物理事实消费后，同动作下一击立即看到结果。动作结果效果使用真正 hit、实际 hpLost 及引擎确认的 moved；被抓持/蛛网/呕吐中断但已提交的移动尝试保持原费时/费用、不给未完成位移的效果，动作期效果在敌人推进前关闭；不依赖动画帧决定结算
- 架势以护盾前正直接物理伤害消费，盾全吸收仍消费，原零伤/免疫不消费；牵制需要 hit+hpLost>0 才施加，下一次真实主物理概率取骰消费，短路必中不消费。仍取骰的原生100%属于一次实际概率提交
- objectiveClock 是完成的配置客观块，不是玩家命令数。原100 tick客观块及同刻怪物行动结束后，才发扩展时间事实；环境/状态/怪物的 CE 顺序不变。动画暂停、慢动作多个块、死亡/坠落早退均有恰好一次边界，入层补算不重复发放
- 冷却是绝对 readyAt；恢复量、间隔、块大小、满值余数策略均读配置。只给参与模拟的生物累计专注；缓存层效果按绝对时钟到期，读取/预览不会消费或改状态
- 克隆 inheritBuild 时复制已学/装配构筑，以 inherited 记录免费继承的知识来源，避免重复扣点；不复制临时实例或原冷却。原派生 HP/力量只按差额应用一次

## 界面与说明

角色页新增学习、装卸和使用，游戏内新增技能行；目标为八方向只读选择草稿，最终录像保存具体 skillId 和目标 DTO。默认3主动/3被动槽，界面从配置读取，不添加占用原 CE 快捷键的技能按键。

属性/技能效果描述由 schema 词汇自动生成：端口、加法/倍率、幅度来源、每点/分母、钳制上限、舍入、条件、动作、消耗、冷却、持续、逐次消费、中断及前置均本地化。体质显示每点最大生命+3、上限+24；改系数/上限/新增定义无需改描述分支。主动显示实际调整后冷却和资源费用；身份仍标为后续1e。

四种操作按钮始终挂载在固定列，只切换禁用状态；真实双击的第二次点击不会在Vue重绘后变成装备或卸下。

只读投影保留原字段，额外只给 objectiveClock（显示冷却）和当前玩家 skill-build（已学/装配/当前效果/继承知识）。不暴露时钟内部余数、实例分配序号、NPC组件或奖励/来源账本；深冻结、会话/revision失效、显示零RNG不变。回放界面只读，取消不发命令。

角色页保持打开时，GameCanvas 只允许已提交的非回放行动完成动画推进；不会把已付费技能冻结到关窗，也不会顺便推进自动行动/回放。原模态和按住输入隔离、关闭焦点、双击防重复均保留。
