# 4b 任务书：任意刚体形状与 4 向旋转

> 分支 `ext/phase4`（= ext/foundation `b306f01`：4a 全部完成——方形 2×2/3×3 的移动/寻路/落点/环境/战斗/视野/渲染、giants 模块、岩脊兽与沉渊巨像）。设计：`docs/ext/phase4-giants.md` r3 §4.1（刚体移动/旋转/邻接）、§8（形状×朝向位姿图与缓存、§8.2 上限）、§12 **D11=A**（4 向旋转、暂不开放镜像）、**D12=A**（单实体 ≤16 格、单边 ≤16、旋转扫掠 ≤256 格）、§14.2 表 4b 行。前序报告 `phase4a0`–`phase4a5`。

## 范围

1. 把 4a 中“只开放 builtin square-2/3、r0”的能力门推广为：**任意已注册连通 mask（≤16 格）+ 4 向 pose（r0/r90/r180/r270）**的独立刚体单实体。方形保持 r0、零额外姿态成本；未声明可旋转的形状固定朝向。
2. 旋转：转身是一次正耗时动作；必须验证**终态 fit 与旋转扫掠**（扫过的格全部可通行且不碰其他生物/边界），180° 分两段 90° 验证；墙边“终态能放下但扫掠不行”必须拒绝。旋转后命中区/标签同步（为 4c 预留）。
3. 位姿图寻路：节点=(锚点, pose)，边=平移或旋转；静态图 key 加入 shape/pose 集合；缓存与失效沿 4a-1（地形 revision、占位动态复核、LRU 8 组），预算触顶有界退化，不改变路线结果。
4. 将 4a-1/4a-2/4a-3 中所有“方形专用”路径（落点搜索 SquarePlacement、FootprintExposure、接触/去重、渲染轮廓、尾格交互、存档校验）推广到任意 mask + pose：凹角/孔洞是**真实空格**（不占位、不挨打、不画轮廓、可站其他生物）。
5. 正式样例：在 giants 模块中加一个原创非方形敌人（暂定**L 形或长条形**，例如“长条 1×4 可旋转的‘蛇脊蠕虫’”或“L 形”，任选其一，名称/描述原创，数值临时），配场地模板（按其形状实际验算锚点/位姿可达；入口宽度满足转身需要或保证无需转身即可活动），完整贯通占位/环境/攻击/显示/存档。
6. 预算负例：形状格数/单边/扫掠超限、非连通 mask、镜像请求（D11 未开放）在数据校验、创建、读档时拒绝。

不做：命中区战斗/部位破坏（4c）、复合体（4d）、主动转换（4e）。
