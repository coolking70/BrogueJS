## 范围

只针对**方形 square-2 / square-3 刚体单实体**（几何按 N 参数实现，3×3 在 fixture 中同样验证），开放到“原生 fixture 与引擎内可创建的多格 Monster 能真实行动”的程度；**生产内容仍无多格生物**（giants 模块在 4a-4），因此真实 Game 中多格生物由测试 fixture/诊断创建。为此需要把 4a0 中“实际 Game 拒绝空间组件”的防线改为**按能力开放**：square 刚体单实体在本步开放的路径（移动、寻路、落点、位移、环境、存读/录像）可用；复合体、旋转、任意 mask 生产使用、zone 战斗、转换仍拒绝。

1. **整体移动**（§4.1）：锚点一步、整体 fit、自重叠合法、多格保守对角（两个正交中间锚点都 fit）；1×1 原墙角语义不变。
2. **体型寻路**（§8）：锚点通行图（fit = 身体格 AND）、按体型距离图（目标=可攻击接触锚点集合）、缓存 key/失效（地形 revision、占位 revision），统一地形变更通知（Promotion/门/Grid.setTerrain/DF 等写入点）；NPC 追击/游荡/逃跑/回归用体型图，下一步实时验整体占位，被堵有界重规划/等待。无多格生物时不建图、不计数、不扫描。
3. **落点与位移**（§4.2 表）：生成/出生、交换（任一参与者多格则不自动交换）、击退/力场、拉拽、闪现/瞬移、随机传送、召唤/克隆（大型复制保留尺寸，小召唤物也查尾格）、polymorph（D07=A：可被变形，变形需先求合法落点再原子提交，无位则整次无效）、坠落（全部有效支撑无地才坠落，D04=A）、换层/pending、休眠唤醒。全部有界、确定性，失败不半提交。
4. **环境接触**（§5.1–5.3）：FootprintExposure 摘要；火/熔岩/气体/蛛网/毒苔任一格接触生效、同一效果按实体一次；深水规则；陷阱每个真实机关一次；门开启；DF 作用域去重；死亡掉落一份。
5. **持久化**：多格生物（square 单实体）在真实 Game 中 save/load/逐条 replay/seek/续录一致；占位索引从实体真相重建。

不做：攻击/命中/射线/范围收集与视野感知（4a-2）、渲染（4a-3）、giants 模块与场地（4a-4）、3×3 正式内容、任意 mask/旋转、复合体、zone 破坏、主动转换。
