## 范围（square-2/3 独立刚体，fixture 创建，生产内容仍无多格）

1. **近战**：玩家与 NPC 对方形身体的近战接触以最近合法接触对判定（含墙角/穿墙行为规则），命中任一身体格=命中该实体；防御/伤害/符文/抓持/反伤/击杀/日志/growth `physicalResolved` 全部一次。大型者的普通攻击只打一个相邻敌人。击退方向、血迹、浮字位置用实际接触格。
2. **几何武器与范围**：横扫/矛/鞭/穿刺/连枷/突进（玩家与 Monster 的实现、growth 技能经 `validateAction`）、爆炸/火球/闪电等范围效果——按 **D08**：物理/范围伤害按 **part** 去重（独立刚体无 zone 时即每实体一次），整体精神/身份效果按 **group** 一次；使用 4a0 的 `collectBodyTargets` 与调用方传入的 scope。独立子段/独立攻击仍各自一次。
3. **弹道/投掷**：第一格身体接触即碰撞；穿透弹道对同一多格实体只解算一次生物效果，反射骰只在首次碰撞采样；**1×1 既有反射重访语义保持**，需混合场景测试。
4. **目标**：自动选敌按唯一实体、最近合法公开接触格排序；手动瞄准仍记录点击格；尾格点击解析为同一实体。prepared 风险确认（D4/2d 协议）对多格目标正常工作，陈旧目标/移动不扣费。
5. **视野与感知**：玩家看见任一占格即可见（身份门槛沿 MonsterVisibility）；大型者看见目标以任一身体观察格对目标任一占格有合法 LOS；隐身/气体显影按实体一份状态；潜行/嗅觉/警觉以 footprint 最近距离摘要后**只掷一次**；噪声唤醒按占格最小值一次；发光原点取稳定身体中央格；身体遮光覆盖全部占格。
6. **关系**：按 D03=A 无自然大型盟友，但支配/魅惑/纷争等通用关系转换对 square 生物可用（无 Boss 额外免疫），被支配后作为盟友的移动/跟随使用 4a-1 的体型能力；不能自动交换位置的规则保持。

**与 3a0 的边界**：合并时为避免误用，已在 `ActorCombatResolution.eligible` 加了“actor-action 路径遇 spatial 生物即拒绝”的守卫（3a0 原意也是在多格接入前关闭）。本步只开放**原生战斗路径**（CombatSystem/Game/Monster 现有攻击入口）；actor-action（combat 模块）对多格的开放留给阶段 3 的 3b，本步不要移除该守卫，但请把你的 body-target 收集接口写成 3b 可直接调用的形态，并在报告列出。

不做：渲染与 UI（4a-3）、giants 模块与内容（4a-4）、任意 mask/旋转/zone/复合体/主动转换。
