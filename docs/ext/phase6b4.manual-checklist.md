# 6B4 维护者浏览器逐项清单

D7 已裁定由维护者执行。本文件所有项目前均为**待验**；SFC/SSR/引擎测试不替代浏览器结果。针对最终真实生产构建，填写报告末尾的源码/dist身份，记录 URL、浏览器版本、DPR、seed、模块/预设、动作及仓外证据路径。受控稀有装备需明确标注，截图不提交仓库。

## 320×568（待验）

- [ ] 无页面横向溢出；长词缀/目标类换行；双戒纵排；确认/取消/返回可达；触控目标≥44×44px。
- [ ] 默认loot推荐growth，显式关growth仍能创建；预设模态、取消/返回、忙碌加载态和重开正常。
- [ ] 武器/甲/戒指各用一张卷轴；目标、前后等级、真实属性/比较一致，双戒槽位正确，非loot目标仍是当前原生行为。
- [ ] 上限前→恰好上限→精炼→全部满值拒绝；未知/部分已知/唯一/腐化均有可信文案，负面不消失，解咒与知识没有混淆。
- [ ] 从读卷轴起取消、无合法目标、目标陈旧、重复触控/Enter/Space、长按键、忙碌/ACK期间操作：卷轴、回合、growth收据没有重复或提前消费。
- [ ] 固定和随机武/甲符文真实触发前后，只有匹配行出现；slaying/immunity目标在允许时才显示，失败/不匹配/无收益不误揭示。
- [ ] 原生详情、loot详情、native↔loot比较、角色来源同步；未知值不出现，无强度作用者不显示虚假提升，卸装/否定后旧结果不残留。
- [ ] 展开/比较/排序/滚动/反复开关不走回合、不鉴定；模态内背包字母、方向键、i/d/a/j/./x不穿透地图，Esc逐层返回，点击一次只提交一次。
- [ ] 保存/读取、录像/seek、死亡/换局后无陈旧目标/确认框；回放只读，续录后状态一致；浏览器控制台无新错误。
