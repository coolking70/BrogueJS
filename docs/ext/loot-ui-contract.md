# loot UI 当前合同（6Z）

候选 `06682d5`，2026-10-17。module/rules0.9.0、pack0.6.0、实例6/state2。B2–C4历史实施与失败记录留各步报告，现行行为以[配置手册](loot-config.md)、下列真实类型和[U01–U18](phase6z.manual-checklist.md)为准。

## 只读数据与入口

`ui/knowledge.ts` 提供 `projectLootKnowledge`，`ui/types.ts` 定义 `LootKnowledgeFacts` / `LootKnownItem` 及卡片/比较/分解/插槽/工位的文本引用与DTO，`gameView.ts` 提供 `readLootGameView`，`gameSession.ts` / 组件负责实际会话。公开类型直接引用源码，避免复制过期签名。

宿主从真实物品位置、原生鉴定/种类知识/诅咒/幻觉构造事实；UI不得拿秘密实例字段自行拼DTO。地面、背包、装备、容器有不同可知性；地面隐藏物等/词缀秘密，未知戒指隐藏种类，幻觉隐藏稀有秘密。主动嵌入的孔/序列可知，不等于底材已鉴定；完整成词替代单符文行。part只在允许的已鉴定视图给通用来源，不透露body/part。

真实四槽比较使用属性管线 `hypothetical(knownOnly)`，包含整组套装阈值损益与两个戒指目标；未知行不泄露、不计入已知收益。旧纯β预览公式不是真实机械收益。源项、条件与原生符文强度分开标注；增加HP/focus容量不补满，减少钳制。查询、展开、排序、滚动、过滤草稿与比较不得触发事务、随机数、知识或时间。

## 比较与隐藏信息的细则

- 戒指目标沿真实装备命令：双空仅左槽、已有单戒取空槽、双满分别比较左右替换；已装备候选只展示当前槽，不提供重复装备动作。原生↔loot两侧保留可知条件/符文的增减，不为原生物品伪造loot DTO。
- `LootKnownAffix`未知行只有位置；已知行才能携带ID、tier、值及合法目标。`LootTextRef`使用完整nameKey与params，组件直接渲染引用，不解析ID推断秘密。
- 地面词缀数与物等隐藏；包内未知或部分已知分解用公开可行区间，混合批次逐项合计上下界。完全已知才给精确产量；侦测魔法不能单独推断历史腐化。
- 装备、套装身份和词缀知识分别判断；孔/序列主动可知不揭示底材，未知套装成员不泄露其奖励。已知条件、原生符文强度与无条件标量分行，不能合成一个虚假的确定收益。

## 命令、CAS与反馈

装备/卸下由 `executeItemCommand`；过滤、分解、碎片鉴定、镶嵌和工位由 `executeCommand`。UI只传合法ID、明确操作及revision，真实目标/费用/权限在提交时重新验证；工位使用稳定rowId，不能以列表序号提交。取消、No、无目标、陈旧CAS、缺料、忙态、满输出、异常均无部分扣费/重发；成功后才耗卷轴/符文/碎片和时间。

五档过滤草稿在轮询期间保持，应用才提交0tick命令，同值去重。单件/批量分解、唯一/套装/镶嵌/成词损失警告齐备；未知产量用合法区间。强化/精炼上限与负面保留、原生随机符文触发知识、套装计件、插槽材料与成词、工位拆卸/重铸、craft固定基底≤magic均已实现。site不显示空入口。仅loot、缺growth/giants/crafting/settlement时按实际能力隐藏/解释入口，不私引包实现。

箱内只读，取回走宿主原入口。工位接单托管/输出预留/退款由WorldWork原子事务所有；UI显示10碎片/100工作tick、劳动锁定、重铸可能变差与失效原因。错误反馈不得被下一次只读刷新清空；重复点击不会重复创建/扣费。

## 会话、文本与布局

关闭/换局/load/seek/死亡清目标、草稿、回调与键盘监听；回放只读。主模态、ACK、确认、动画忙和营地面板互斥；方向/物品字母/快捷键不穿透地图，Esc逐层返回，触屏滚动/长按/双击只提交一次。

文字通过 `LootTextRef.nameKey + params` 和模块 `locales/ui.zh_CN.json`；机械目录nameKey/descriptionKey与展示文案区分。禁止拼接翻译键、硬编码玩家文本或孤立按钮。组件不自行解析秘密affix ID。界面 `.loot-` 前缀、容器查询、双戒窄屏纵排、44×44触控目标、深浅稀有色保持。

生产入口为新局预设、实际背包/检视/比较/过滤/角色来源与工位；工具画廊不进入生产。SFC/SSR或引擎自动验证不等于浏览器通过；维护者统一执行320×568、800×900、1440×900的U01–U18，各格当前待验。
