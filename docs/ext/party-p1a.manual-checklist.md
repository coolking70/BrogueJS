# P1a 维护者浏览器验收清单

2026-10-18：本轮按维护者指令未运行浏览器或真机。下面项目均为 **待验**；Node Worker 和 Vue SFC 测试不替代浏览器结果。请记录候选源码身份、浏览器/设备、窗口尺寸、动画设置、种子、录制文件和第一处分歧；截图及大文件放仓外。

- 桌面与 320/390 CSS 像素触屏各完成一次 party-only 两人创建；再试全开四人、无 growth、无 loot，取消/返回/快速双击提交。
- 四人焦点按钮、就绪提示、成员 HP/状态、背包标题/双戒指替换、成长分配、合成与营地界面均对应当前成员。切换只影响显示。
- 用两人自然完成一层：移动、攻击、拾取、装备、吃食、搜索、投掷、交换。检查同 tick 等待第二人，不自动替空闲成员等待。
- 非主成员执行采集、双批次制作；批次间用等待继续或取消退款。分别建立营地、建箱、存取、休息，检查主成员物品不被扣除。
- 不同 LOS/隐形/心灵感应下检查共享显示；另一成员的可见目标不得直接授予当前成员射击资格。
- 在危险移动、物品目标、成长/生产确认期间切换焦点；确认内容、费用、目标和录像执行者仍属于原发起成员。新局/读档后的旧确认不能提交。
- 楼梯旁全员同行、远离拒绝、明确留守、单人成坑、返回恢复；主成员死亡后另一人继续，活动成员全死时选择留守层恢复。
- 护符分别放次成员和留守者背包；入口与最深层出口必须显式整队确认，取消无终局，确认只结算一次。
- 真实浏览器 Worker：保存→继续→保存→加载→seek→续录；255/256/257、2047/2048/2049 边界；等待期间切焦点、动画开关、新局与读档取消旧任务。
- 桌面与触屏分别检查背包、模块面板、确认框和 Party HUD 不遮挡关键按钮；布局、触控和 FPS 单独记录。真机尚无任何性能结论。
