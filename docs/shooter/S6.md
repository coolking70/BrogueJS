## 行动循环

默认进入本地指挥台。三个区域选择一项，建立三场连续任务的行动；战略界面不推进机械时钟。每场独立生成稳定 seed，依次使用原布局、水平镜像、垂直镜像，目标/墙/环境/出生点一起变换。同一主链仍是两站扫描、三巢穴、上传、累计撤离，可选救援与两类 POI 保留；本阶段没有新增三种不同任务类型。

部署冻结装备、升级、布局和难度。完成当前任务后点击“结算并返回指挥台”，领取本场奖励并推进下一场；任务间可购买/换装。失败结束行动，保留此前已领取资源，可以重新建立行动。三场成功额外 150 点数、3 样本，并解锁下一难度。序号持久增加，每场 ticket 唯一；过期/重复 ticket 不能结算，账号再次收到同一奖励 ID 不会增加余额。事务失败恢复操作前的战略状态。

| 难度 | 出战机会 | 群体数量与增援上限 | 精英 | 主奖励点数 |
|---|---:|---|---|---|
| 巡逻 | 6 | 原 S5 数值 | 原数值 | 原数值 |
| 突击 | 5 | ×1.25，向下取整，最多 200 | 原数值 +1，最多 8 | ×1.25 |
| 围攻 | 4 | ×1.5，向下取整，最多 200 | 原数值 +2，最多 8 | ×1.5 |

Boss 上限仍为 1；任务时限、区域防守与撤离累计计时未缩短。战略区域仅是本地行动入口，没有全球战争或服务器状态。

## 军械库

新账号 100 点数，手枪/步枪、补给/扫描已解锁。行动携带两种枪械；界面固定手枪为备用，另选主武器。槽位和原 1–4 / 5–8 键保留，未携带的枪械或未解锁支援不显示、不执行请求；手柄 Y 只循环当前携带枪械。

| 内容 | 点数 |
|---|---:|
| 霰弹枪 / 榴弹 | 80 / 120 |
| 炮塔 / 轰炸 | 100 / 120 |
| 任意支援升 Ⅱ / Ⅲ | 80 / 140 |

Ⅱ / Ⅲ 级支援冷却分别减少 15% / 30%，整数 Tick 向下取整；其余效果与友伤规则保持。样本计入永久资源，目前不设置消耗入口。普通备用弹仍无限，弹匣/换弹与 S4 头顶进度反馈保留。

训练场可使用当前安装的全部战斗装备，不发永久奖励；录像导入仅恢复机械世界，不领取永久奖励。正在出战时，训练入口改为继续当前出战，不能通过重开/导入覆盖未结算任务。

## 边界与持久化

新增独立 `operations` / `meta-progression` 包，分别拥有数据、规则 fingerprint、状态、descriptor、词汇与自有测试；不依赖对方或任何战斗模块。通用 `StrategicRuntime` 只提供受控接口，产品 `CampaignSession.execute` 拥有战略命令事务。可选联动在产品组装层：无 meta 的行动使用全部枪械/基础支援且不限制难度；无 operations 时军械库可独立管理，不产生行动奖励。没有 missions 时指挥台禁止部署，训练场仍可游玩。

战略 manifest / 命名空间与机械 manifest 分离。战斗只持有冻结 `BattleSetup`；模块收到带冻结数组的独立只读副本，无法修改或持有内部对象的可写别名，不读取浏览器、战略账号或 UI 时钟。firearms 1.3.0、support 1.1.0、missions 1.2.0；operations/meta-progression 均 1.0.0。旧机械规则版本直接拒绝。

Shooter Profile `shooter-s6` v6；snapshot/replay `broguejs-shooter-s6` / `broguejs-shooter-s6-replay` **v7**。训练检查点键 `broguejs-shooter-s6-checkpoint-v7`。战略 `broguejs-campaign-s6` v1，页面键 `broguejs-shooter-s6-campaign-v1`，一个 JSON 原子保存账号/行动/出战绑定/机械检查点。出战每 300 Tick（10 秒）、终局与手动保存时更新；暂停在同一 Tick 不重复写入。刷新后从指挥台继续当前出战，最多回退到最近自动保存；单局检查点与录像不能替换当前绑定。续录沿用既有检查点后缀录像合同。

进度仅在同一浏览器/站点本地保存，无云同步；开发阶段不迁移 S0–S5 档。手机/手柄的战斗输入沿用 S5；战略选择目前通过按钮与选择框。原始截图/录像/日志在仓库外。
