## 运行与操作

```bash
npm ci
npm run dev -- --host 0.0.0.0
# 在 Vite 地址下打开 /shooter.html
```

- WASD / 方向键：移动。标准映射手柄：左摇杆。触屏：左侧圆形摇杆。
- 相机连续跟随玩家，右上角小地图显示位置与视口。方向短线仅用于看清朝向，尚不支持瞄准。
- 青蓝色为浅水（半速）；橙色为火焰，绿色为毒气。火/气只累计接触 Tick，尚不造成伤害。
- 原来的动作诊断、暂停、单步、种子重开、检查点、录像导入导出与完整重放验证仍可用。
- 窗口失焦或切换后台会暂停并清空输入，返回后手动继续。键盘松开、触摸取消/丢失捕获、摇杆回中均停止移动。
- 控制器优先级：活动触摸 > 有方向的键盘 > 标准映射手柄。未识别映射的手柄保持无输入。

`npm run build` 仍同时产出 Brogue 和 Shooter 两个入口；未修改原 Game 的启动与命令路径。

## 权威位置与移动合同

| 项目 | S1 合同 |
|---|---|
| 空间 | 每格 1,024 WU；圆形半径 280 WU；整数 `pose.x/y/facing` 是真相 |
| 兼容格坐标 | `loc = floor(pose / 1024)`；只作投影，读档必须交叉验证 |
| 平地速度 | 160 WU / Tick，即 4.6875 格 / 秒 |
| 输入 | 每 Tick 一条 int8 moveX/moveY；机械入口仍为 `advanceTick` |
| 方向归一化 | 整数平方根向上取整，不允许斜向速度加成；允许小于 1% 的量化减速 |
| 移动余量 | 65,536 分之一 WU 的整数 credit；随存档恢复；松轴及对应碰撞清除余量 |
| 碰撞 | Grid 不可通行格与圆形角色；连续 sweep 后最多四次接触滑动 |
| 积压 | 墙角剩余位移当 Tick 丢弃，不积累为日后的移动债务 |
| 渲染 | 只在前后机械快照之间插值；相机、Pixi、设备浮点数据不写机械位置 |

原 `CreatureSpatial` 的多格语义没有改成圆形。新的 `KinematicSpatial` 接收真实 Grid；当前诊断角色保存 `pose` 与 `loc` 镜像，尚未把完整 Creature、原 AI 和原 Game 移入实时 Session。

## 空间底座

新增的 `src/engine/Movement/` 文件：

- `WorldUnits.ts`：坐标、整数平方根、格投影、移动余量。
- `KinematicCollision.ts`：圆与地形/角色的扫掠、滑动和穿透拒绝。圆角采用两矩形与四圆的并集，不把圆体当作外扩方盒。
- `SpatialHash.ts`：按桶查找候选实体，结果按 ID 稳定排序、去重；索引由权威位置派生，不进存档。
- `SpatialQuery.ts`：`queryCircle`、`queryAabb`、`raycast`；射线复用 sweep。
- `KinematicSpatial.ts`：从所有地形层计算圆形身体的接触格，按 y/x 顺序输出。

碰撞求交采用 BigInt 判别式与整数平方根，TOI 保守量化到 1/1,048,576 Tick。平墙使用精确整数接触面，曲线接触可能保留极小的整数安全间隙；最终位置重新检查无穿透。四次滑动预算耗尽时停在合法位置。

单次 sweep / raycast 每轴最大 4,096 WU，半径最大一格；调用者须提供非穿透起点，`moveCircle` 会拒绝穿透起点。当前移动远低于此上限。长距离弹道、动态刚体、移动平台、堆叠和穿透恢复均不是本阶段能力。空间服务不引用 Vue、Pixi、DOM、墙钟或原 RNG singleton。

## 地形与客观时间

`ShooterArena.ts` 构造固定 40×28 格诊断场，直接复用 Grid、分层地形和通行属性；不是新的程序生成算法。包含墙角、开放门洞、浅水、火焰、毒气和一个可碰撞的静止角色。

一次 Tick 的顺序为：规范输入校验 → 使用移动前接触决定速度 → 连续移动与碰撞 → 更新位置/loc/派生索引 → 重算接触与累计曝光 → 既有动作调度一次 → 保存 RNG 与输入 → 发布快照。

圆体与格子有正面积交集才算环境接触，单纯相切不触发。任一接触格含浅/深水时下次移动半速；火、气分别每 Tick 累计一次，即使站立不动或同时覆盖多个同类格也只加一次。接触检查基于完整地形层，不依赖顶部显示地形。浅水离开后恢复速度，没有借用玩家回合计时。

本轮没有接入原 Game 的火焰传播、气体扩散、伤害、地形推广、饥饿或 AI。接触计数是可验证的空间/时间接口，不冒充完整环境玩法。

## 存档与重放

产品变为 `shooter-s1`，格式 `broguejs-shooter-s1` / `broguejs-shooter-s1-replay`，version 2，地图版本 `s1-movement-lab-v1`。localStorage 使用独立 S1 键；S0 文件明确拒绝，不自动迁移。

保存精确 pose、loc 镜像、半径、移动余量、接触格、三类接触 Tick，以及此前的动作与 RNG 全状态。加载前验证地图版本、整数范围、镜像、接触重算与角色/墙体非穿透。重建空间索引，不保存缓存。

录像仍由同一个 `advanceTick` 重执行 InputFrame，并比较完整最终状态。从检查点恢复后以该点为新的录像起点；不声称保留之前的输入来源。S0 的一小时录制预算仍保留。
