日期：2026-10-05。基线：`2b8b8c29e5e3b7702df1e5f9c7ed574b8fcb1ad3`。分支：`product/shooter-prototype`。

## 实施

按维护者“继续下一阶段”授权实施 RFC S1。新增整数 World Unit、圆形 sweep/slide、派生空间索引与查询、真实 Grid 分层地形接触、WASD/标准手柄/触摸摇杆及连续镜头。存档与录像升为 S1 v2，保存和验证精确位置、loc、移动 credit 与环境接触状态。使用说明与界限见 [S1.md](S1.md)。

既有 ActorActionScheduler、Random、Game、CreatureSpatial 和玩法模块没有修改；本轮不是完整世界实时化，也不包含枪械。

## 专项证据

- 新增两份测试，26 项；既有时钟/动作/重放测试继续执行，共五份 Shooter 测试。
- 高频跨格 sweep、贴墙滑动、从接触面退开、圆角空间、对角墙缝、窄通道、开闭门、角色碰撞与空间查询。
- 1,200 次固定种子的对抗位移序列，以独立的每格矩形距离断言检查无穿透，并限制位移不超过请求距离。
- 三种设备适配生成相同 InputFrame，逐 Tick 比较 1,500 Tick 机械轨迹；覆盖死区、回中、断开、未映射手柄、反向按键和释放。
- 多个运动中途检查点精确恢复；连续续录及重放；非法版本、位置/格镜像、地图版本、credit、接触和穿透拒绝。
- 实际浅水半速；静止于火/气区域时每 Tick 累计一次，不因覆盖多格而重复。
- 冷 Node bundle 在禁用 `Date.now()` 且无 DOM 的环境中完成导入和两个独立 Session 的首 Tick 移动。

## 修复记录

初次类型检查发现阶段字符串替换误改了诊断按钮常量名，统一为阶段无关的 `PULSE_BUTTON` 后修复。

首次新增专项测试 48 通过、2 失败：一项斜缝测试的起点已侵入圆角，修正为合法起点，保留阻塞断言；另一项发现保守 TOI 量化使直墙停在接触面前 1 WU，生产代码改为使用精确整数平面位置并继续验证非穿透，原精确位置断言保留。

S0 的“moveX=1 应拒绝”前提随 S1 开放移动而失效，改为非法 int8 值 128，保留输入拒绝与无状态修改断言。原 FPS 测试新增周期移动，不删除动作、RNG、积压和多 Session 断言。其余既有测试断言未放宽。

## 界限

手机检查为 Chromium 390×844 模拟触屏，手柄为标准映射注入样本；没有手机实机或实体手柄结果。S1 的 Go/No-Go 主观手感仍交维护者试玩。

本轮使用固定训练场，没有改程序地图生成，未运行 drift。按扩展分支政策不获取 CE 源码、不跑 `test:full` / `test:gen`。没有模块实现或依赖改造，不声称执行物理删除矩阵。原主产品行为继续由完整测试与真实 Game 全子集 smoke 验证。

火/气尚无伤害或传播，未接入完整 Game 的环境/AI、Growth/Narrative/Giants 实时生命周期；长距离弹道、枪械、尸潮、任务、支援和联机留到对应阶段。
