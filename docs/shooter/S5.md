# S5 — Support

维护者确认 S4 试玩与下一阶段计划后授权实施。基于 `product/shooter-prototype` 的 `24939bbcd51a8acca50ca53c805084cc53c54d7e`，新增独立 `support` 模块，并沿用现有完整任务。没有合回 main 或开发长期成长、多人。

## 可玩内容

默认开启 firearms、hordes、missions、support。仍保留普通枪械无限备弹、真实弹匣/换弹和 S4 的累计撤离。支援默认开局可用；接受有效呼叫时开始独立冷却。所有时序均为 30 Hz 整数 Tick。

| 支援 | 到达 | 效果 | 冷却 |
|---|---:|---|---:|
| 补给舱 | 2 秒 | 地面补给存在 90 秒，可领取两次；活着且有资源缺口时补满生命和所有枪械弹匣，取消当前换弹但保留射击冷却。已全满不消耗次数 | 90 秒 |
| 自动炮塔 | 3 秒 | 自动攻击八格内、无遮挡的敌方目标；按距离和实体 ID 稳定选取。持续 45 秒，90 发，每半秒 25 伤害 | 60 秒 |
| 区域轰炸 | 3 秒 | 红色危险圈预警，三格范围，中心 500 伤害并按距离衰减；墙体遮挡，逐实体结算，能伤到调用者。清除同范围、无遮挡的火焰和毒气 | 45 秒 |
| 扫描侦察 | 1 秒 | 十四格内的敌方目标揭示 20 秒，包括墙后目标。显示轮廓、生命条和小地图位置；没有伤害 | 40 秒 |

补给、炮塔、扫描投放范围八格，轰炸十二格。落点必须是可通行地面；越界、超出范围、冷却中或倒下时的请求不消耗冷却。投放在呼叫后独立完成，调用者死亡不会撤销已确认支援。同类新投放替换仍在场的旧实例。炮塔是模块自有部署实体，首版不阻挡移动、没有可受击生命，按时间/弹药结束；不会开火伤到玩家。

启用 support 时，小地图通常显示四格内敌人；扫描扩展可见敌情。任务设施仍可见。不启用 support 时保留原完整敌人小地图。扫描不改变攻击 LOS。

## 操作与反馈

- 键鼠：5–8 选类型，Q 循环选择已就绪类型；点击地图选落点，F / Enter 确认，Esc 取消。
- 手柄：LB 循环选就绪支援，右杆选方向（默认离角色四格），RB 确认，B 取消；RT、X、Y、A 保留射击、换弹、切枪、交互。
- 触屏：点击支援按钮，点击地图调整落点后确认；也可用右杆选方向。选点期间右杆只瞄准，不射击。
- E / A / 交互按钮领取附近落地补给；补给确实改变资源时优先消耗这次交互，没有资源缺口时允许交互继续传给任务。
- 投放圈、到达倒计时、补给次数、炮塔弹药和扫描目标数量显示在对应世界位置；支援栏显示冷却。相邻/同点的支援标注自动堆叠，并避开已有头顶读条。保留换弹与区域任务头顶读条。
- 选点和取消只改变 UI 状态；确认后的整数坐标和 slot 进入规范化 Command。暂停、失焦、重开、读档清空未确认选择。

## 边界与版本

`support` 拥有数据包、definitions、运行状态、部署实体、冷却、命名空间、descriptor 和模块自有测试。只依赖通用底座，没有导入其他模块。Host 提供受控 replenish / clearHazards，统一伤害 authority 继续拥有所有 HP 写入；枪械通过可选 replenish 能力接收补给，没有枪械时只治疗。没有 missions/hordes 时也能呼叫支援。

清除的 authored hazard 坐标由产品保存；恢复前严格校验唯一性、坐标与原地图火焰/毒气，再重建实际 Grid 和 actor contact mirror。伤害、扫描、小地图和接触状态均来自同一机械快照，没有 UI timer 或规则 RNG。

ProductProfile `shooter-s5` v5；Shooter snapshot/replay **v6**，格式 `broguejs-shooter-s5` / `broguejs-shooter-s5-replay`。support 1.0.0，firearms **1.2.0**（新增补给行为），hordes/missions 未改自身规则版本。旧 S0–S4 档/录像直接拒绝，不迁移；试玩请重新开局。

验收结果见 [S5 实施报告](S5-report.md)。S6 Operation / Meta 仍需本阶段试玩后进入。
