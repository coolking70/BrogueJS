# DESIGN-3b：沉浸模式与设置页打磨

> 分支：`design/new-theme`（工作区 `BrogueJS-newtheme`）。前置：DESIGN-3（刻符唯一界面 + 沉浸模式），报告见 `docs/reports/design-3-glyph-default.report.md`。

## 背景
Claude 在浏览器中按 1280×800、768×1024、390×844、844×390 验收 DESIGN-3：刻符默认布局四视口均通过；沉浸模式与设置页有以下问题。用户已确认按此整改，并同意**手机默认仍关闭沉浸模式**。

## 待修问题

### 沉浸模式 · 桌面（1280×800）
1. **地图没有铺满**：地图画布左右仍有大块黑边（地图区域是中间一块灰色矩形），与"地图铺满"的设计不符。DESIGN-2 评审整改（bec53f9）曾为 umbra 实现过"覆盖视口 + 按浮层实测位置留安全边距"的镜头（`computeMapCamera` 的 fillViewport、`mapOcclusion.ts`），DESIGN-3 删除 umbra 时一并删掉了其中部分分支；可参考 `git show bec53f9` 复用思路。要求：沉浸模式下地图铺满可用区域、不出现左右黑边，玩家及周围几格不被顶部状态行、底部消息行、命令环按钮遮挡。刻符默认布局的地图呈现不得改变。
2. **底部消息行过高且消息偏到最右**：底部空出一大条，消息文字挤在右边、远离视线中心，命令环按钮压在这条带子上。要求：消息行紧凑（单行高度），文字左对齐或与地图对齐，命令环按钮不遮挡消息文字。

### 沉浸模式 · 手机竖屏（390×844）
3. **状态行只剩数字**：显示为"1 1 30/30 饱食"，缺少深度/回合/生命等标签，无法辨认。要求：保留最少必要的标签或图标，让每个数字可辨认（仍保持单行）。
4. **没有方向键**：沉浸模式在触屏上隐藏了 DPad，只剩命令环，无法逐格移动（只能点地图寻路），战斗不可用。要求：触屏（粗指针或紧凑视口）下沉浸模式保留可用的逐格移动方式——保留 DPad，或在命令环中加入方向，或其它不比 DPad 更难用的方案；在报告说明取舍。
5. **看不到消息行**：手机沉浸模式下没有显示消息行。要求：保留单行消息。
6. 地图上方空出大片空白：在不遮挡的前提下让地图利用纵向空间。

### 设置页
7. **"字形图鉴"按钮是一个突兀的大方块**，与其它设置项（下拉框、复选框）风格和尺寸不一致。改为与其它设置项一致的样式（例如一个普通按钮或一行"查看"入口）。
8. **展开图鉴时左侧标题 logo 往下跳**：设置面板变高导致标题区随之重新垂直居中。要求展开/收起图鉴时标题不跳动（例如图鉴在面板内滚动、限制设置面板最大高度，或标题区不随面板高度居中）。
